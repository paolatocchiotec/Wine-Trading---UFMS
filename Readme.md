# Wine Trading

Projeto desenvolvido para a disciplina de Projeto Integrador do curso de Tecnologia da Informação da UFMS Digital.

O projeto consiste no desenvolvimento de um site para a Wine Trading, empresa do ramo de vinhos. O site ainda está em desenvolvimento e está sendo construído utilizando WordPress e ferramentas complementares.

## Tecnologias utilizadas

Até o momento estão sendo utilizadas as seguintes tecnologias e ferramentas:

- WordPress
- Elementor Pro
- WooCommerce
- Code Snippets
- HTML
- CSS
- PHP

O WordPress é utilizado como base do projeto. O Elementor Pro está sendo utilizado na construção e organização visual das páginas. O WooCommerce está sendo utilizado para o cadastro e gerenciamento dos produtos.

O plugin Code Snippets está sendo utilizado para inserir códigos em PHP sem a necessidade de editar diretamente os arquivos principais do WordPress.

Também estão sendo utilizados códigos CSS para personalização de elementos específicos do site.

## Etapas já desenvolvidas

### 1. Instalação e configuração inicial

Primeiramente foi realizada a configuração do WordPress e a instalação dos principais plugins necessários para o desenvolvimento do projeto.

Foram instalados:

- Elementor Pro
- WooCommerce
- Code Snippets

Após essa etapa, iniciou-se a criação da estrutura visual e funcional do site.

### 2. Desenvolvimento da página Home

A página inicial foi criada utilizando o Elementor Pro.

Nela foram adicionadas seções de apresentação da empresa, categorias de vinhos, produtos em destaque, informações institucionais e elementos visuais relacionados à identidade da Wine Trading.

Também foram realizados ajustes de layout e responsividade para melhorar a visualização em diferentes tamanhos de tela.

### 3. Cadastro dos produtos

O WooCommerce foi instalado e configurado para permitir o cadastro e gerenciamento dos vinhos.

Os produtos estão sendo cadastrados com informações como:

- Nome
- Imagem
- Descrição
- Preço
- Categoria
- Informações específicas do vinho

Após o cadastro, alguns produtos foram inseridos também em seções da página inicial.

### 4. Página de produtos

Foi criada uma página específica para exibir os produtos cadastrados no WooCommerce.

Essa página permite que o usuário visualize os vinhos disponíveis de forma organizada, facilitando o acesso aos diferentes produtos da loja.

### 5. Página do carrinho

Também foi criada a página de carrinho do WooCommerce.

Nessa página o usuário consegue visualizar os produtos adicionados, quantidade, valores e demais informações relacionadas à compra.

Foram realizados ajustes de personalização utilizando CSS para melhorar a aparência da página e deixá-la de acordo com a identidade visual do projeto.

### 6. Uso de PHP

Durante o desenvolvimento também estão sendo utilizados códigos em PHP através do plugin Code Snippets.

Esses códigos são utilizados para realizar ajustes e personalizações específicas no funcionamento do site e do WooCommerce.

O uso do Code Snippets permite realizar essas alterações sem modificar diretamente os arquivos principais do WordPress.

### 7. Uso de CSS

O CSS está sendo utilizado para personalizar diversos elementos do site, como:

- Cores
- Fontes
- Espaçamentos
- Botões
- Produtos
- Carrinho
- Organização dos elementos em diferentes tamanhos de tela

Em algumas páginas, o CSS personalizado foi inserido diretamente através das ferramentas do Elementor Pro.

### 8. Responsividade

O site está sendo desenvolvido para funcionar em diferentes dispositivos.

Estão sendo realizados ajustes específicos para:

- Computadores
- Tablets
- Celulares

A responsividade está sendo verificada durante o desenvolvimento utilizando os recursos de visualização responsiva do Elementor Pro e testes em diferentes tamanhos de tela.
