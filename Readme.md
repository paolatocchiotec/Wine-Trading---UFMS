# Wine Trading

Projeto desenvolvido para a disciplina Projeto Integrador.

O projeto consiste no desenvolvimento de um site para a empresa Wine Trading, com o objetivo de apresentar a empresa, seus produtos e facilitar o contato com os clientes.

## Tecnologias utilizadas

- WordPress
- Elementor
- WooCommerce
- HTML
- CSS
- PHP

## Desenvolvimento

Nesta etapa, foram iniciados:

- desenvolvimento da página inicial;
- criação da identidade visual do site;
- cadastro dos produtos;
- configuração inicial do WooCommerce;
- organização das páginas e seções do site;
- adaptação da estrutura para diferentes dispositivos.
