# Banco de Dados do Projeto

O projeto Wine Trading utiliza o banco de dados do próprio WordPress, em conjunto com o WooCommerce.

O WordPress utiliza banco de dados MySQL/MariaDB para armazenar informações da aplicação.

No projeto, o banco armazena informações como:

- produtos;
- preços;
- estoque;
- categorias;
- usuários;
- pedidos.

O WooCommerce utiliza as tabelas do WordPress para organizar essas informações.

A pasta também contém exemplos de consultas SQL utilizadas para demonstrar a leitura dos dados armazenados no sistema.
